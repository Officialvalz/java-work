# ☕ Java Projects

A collection of Java programs built while mastering Object-Oriented Programming, data structures, algorithms, and software design principles.

## 🛠️ Technologies Used
- **Language:** Java
- **Build Tool:** Maven
- **Testing:** JUnit 5 (BDD-style: Given / When / Then)
- **Paradigm:** Object-Oriented Programming (OOP)

## 📁 Projects Included

| Project | Description |
|---|---|
| `AirConditioner` | OOP simulation of an air conditioning system with state management |
| `CaesarCipher` | String encryption using the classic Caesar cipher algorithm |
| `CreditCardValidator` | Card number validation using the Luhn algorithm |
| `CheckoutSystem` | Retail checkout simulation with product and pricing logic |
| `MortgageCalculator` | Calculates monthly mortgage payments based on loan inputs |
| `Nokia3310` | Full simulation of a Nokia 3310 phone menu system (25+ methods) |
| `TransactionLog` | Bank transaction logging system with structured records |
| `SevenWeek` | Multi-week challenge covering core Java concepts |
| `ChristmasSong` | Recursive/loop implementation of the 12 Days of Christmas |

## 🧪 Testing
All testable components are covered with **BDD-style JUnit 5 tests** following the Given / When / Then structure.

## 🚀 How to Run
```bash
# Clone the repository
git clone https://github.com/Officialvalz/java-projects.git
cd java-projects

# Build with Maven
mvn clean install

# Run any class directly
javac FileName.java && java FileName
```
